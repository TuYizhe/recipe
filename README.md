# 我的菜谱

把做过的菜一道一道记下来：用料、用量、火候、先后步骤，以及每次做完的心得。
手机网页（PWA），可添加到桌面离线使用；数据只存在本机浏览器里。

- 首页：海报式翻页菜单，一页一道菜；随节日 / 二十四节气换装
- 做菜模式：一屏一步、屏幕常亮、这一步要放的调料和用量直接列出、步骤里的时间可一键计时
- 做完写一句心得，下次打开第一眼看到
- 买菜清单：同名食材自动合并用量

```
npm install
npm run dev
```
